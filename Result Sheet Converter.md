# Result Sheet Converter

Add DU tabulation sheets in any Excel format (.xlsx, .xls, .xlsm, .xlsb, .ods or .csv). The app reads each sheet’s first tab, builds the Info and Marks files, and shows a summary. Files stay in your browser.

**Choose result sheets**You can select several files at once. All will be combined into one Info file and one Marks file.

Downloads are not available in this view. Open the artifact in claude.ai to save files.
